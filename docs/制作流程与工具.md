# AI 漫剧制作：工具选型与 Codex Cloud 接入

更新：2026-11-24。以下均为公开 GitHub 项目，安装前请复核版本、授权、第三方服务费用。

## 分层架构

| 层 | 当前方案 | 作用 | 是否已经安装到用户的电脑 |
|---|---|---|---|
| 导演 Agent | [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills) | 剧本、角色资产、分镜、提示词、剪辑及 QC | **否**；仓库里已准备安装脚本 |
| 图/视频生成 | 连接第三方图像/视频模型，或按需用 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) | 保持参考脸、首帧、图生视频 | **否**；需要模型/账户/GPU |
| 自动化备选 | [AutoVid OSS](https://github.com/hanmengkai/autovid-oss) | 中文旁白 edge-tts、FFmpeg、整集流程 | **否**；高 GPU/RAM 要求 |
| 可视化工作台备选 | [Hail-Drama](https://github.com/hailcanto/hail-drama) | 角色资产、分镜和逐镜制作管理 | **否**；可后续加入 |
| 剪辑合成 | [FFmpeg](https://ffmpeg.org/) | 转场、字幕、音轨、导出 MP4 | 脚本会检查，缺失则提示 |

主方案优先轻量：使用 Drama Skills 将文字创作阶段先标准化，第一镜审核之后再追加人物参考图和动态镜头；避免一次部署沉重的本地 Wan 全流程。

## Codex Cloud 实际接入

官方环境流程：[Codex Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environments)

1. 在桌面端或网页新任务里选 **Work in > Cloud**，进入 **Select environment > Create environment**。
2. 选择 GitHub 仓库 `alisachenyyy123-blip/alisa`；如果未显示，先连接 Github 授权，并检查该仓库已向 Codex 开放。
3. 点击 **Get started**，让 Codex 分析这个仓库；要求它运行 `bash scripts/setup_drama.sh`，安装并**测试**漫剧技能。配置可写入环境的 Install script。
4. 查看工具安装报告，并选择 **Publish**。**没有 Publish 就不算有可复用云环境**。
5. 在发布后的云环境创建新任务，输入：`读取 opening/EP001_开场制作方案.md，用 short-drama 工作流完成角色资产、分镜审核和图生视频投产计划；先展示生成批次再执行收费模型。`

如果 GPU 视频生成在 Codex Cloud 环境不可用，可用 **云端视频模型服务** 生产镜头，再将生成片段交回 Codex/FFmpeg 合成。ComfyUI 的 Wan 视频生成依赖大量 GPU 显存；仓库只下载源代码并不能代替模型权重或显卡。

## 面向生产的关键规则

1. **先剧本后人设**：核心悬念和人物立场先明确；切勿直接「一句话生成一整集」。
2. **先参考后动态**：用角色定妆图作为所有镜头共同身份锚点；必要时用首尾帧保持场景连续。
3. **每镜仅一个关键动作**：2D 漫剧比复杂多人交互更容易稳定；复杂动作拆镜。
4. **视频模型不直接排中文字**：短信、倒计时、片名、字幕在剪辑阶段叠加。
5. **质检与重试**：检查同一角色的脸型、耳饰/发夹位置、衣服、手指、空间、场景光线，再做局部重生成。
6. **尊重版权**：只使用自有/获授权剧本、人物、音乐、配音素材；开源代码遵守各自许可证，生成模型的商用许可单独确认。
7. **信息安全**：API Key 仅写在环境变量/专用密钥管理器，绝不提交 GitHub。
