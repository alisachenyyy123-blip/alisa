# 免费本地漫剧开头工具链（2026-11-24）

目标：为上传的手机壳产品实拍视频加 5–8 秒「闺蜜吵架」2D 漫剧开头，不使用按次付费的 AI API。**GitHub 开源免费 ≠ GPU 运算免费 ≠ 生成权重可无条件商用。**

## 必备：轻量路线（不需要视频扩散显卡）

| 工具 | 仓库 | 许可证 | 用途 |
|---|---|---|---|
| FFmpeg | https://github.com/FFmpeg/FFmpeg | 主要 LGPL，构建可包含 GPL | 拼接原始视频、字幕、转场、音量匹配、输出 |
| MoviePy v2 | https://github.com/Zulko/moviepy | MIT | 自定义图片推拉镜头、动态字幕、精确到秒剪辑 |
| MeloTTS | https://github.com/myshell-ai/MeloTTS | MIT 代码/项目，模型资源按原始协议复核 | 普通话对白 / 无按次 API 费用 |

## 按需：AI 镜头升级（需要模型和算力）

| 工具 | 仓库 | 许可证 | 用途与限制 |
|---|---|---|---|
| ComfyUI | https://github.com/Comfy-Org/ComfyUI | GPL-3.0 | 节点工作流，本地做漫画关键帧、图生视频，Mac Apple Silicon 支持，模型需另下 |
| LivePortrait | https://github.com/KlingAIResearch/LivePortrait | 检查官方 LICENSE 和权重使用约束 | 角色表情和转头动画，Mac Apple Silicon 路径可用，但不保证动漫脸无崩坏 |
| Wan2.2 | https://github.com/Wan-Video/Wan2.2 | Apache-2.0 代码库 | 高配图生视频，官方 TI2V-5B 720p 示例至少 24GB 显存，暂不列为必装 |

## 现有产品素材的衔接策略

- 首先用**实际产品视频的首帧**确定模特手持姿态、手机背面和画面占比。
- 漫剧开头时让两名女生争执「你是不是动了我手机？」；转折台词「你先看看它！」。
- 漫剧最后一镜必须为手机朝向镜头、轻微推近的**动作意图**，以产品实拍首帧做位置与运动方向匹配。
- 可直接采用 2D 漫剧画面**推拉 / 偏移**（FFmpeg/MoviePy），不用生成复杂多人打斗，也无需在 AI 里重做手机壳。
- 声音先跨切点 0.2–0.4 秒，画面利用短音效和节奏点切实拍，后加中文字幕。
- 原实拍中的手机壳形状、立体装饰、摄像头框、质感、比例均不修改；避免重生成实拍产品。
- 最终 MP4 H.264/AAC、9:16、1080×1920（不足分辨率时不要冒充原生高清）。
- 如需纯粹漫画人物嘴唇真实同步，优先实验 LivePortrait；该部分 **不保证在 Mac 上自动成功**，需实测模型和权重。

## 安装入口（需在有终端的设备或 Codex 环境执行）

```bash
bash scripts/setup_free_intro.sh
```

脚本采用**检测优先**，先创建隔离的 Python 环境并安装轻量 MoviePy/Pillow，不自动下载大模型或收费素材；FFmpeg 未安装时输出 macOS/Linux 的手动安装建议。MeloTTS、ComfyUI、LivePortrait、Wan2.2 仅给出官方仓库链接，确认设备兼容性后再安装。安装脚本记录在 GitHub 并不代表用户 Mac 已运行。

## 许可证提醒

- 用户投放手机壳商品视频时，声音、图片、音乐必须有商用授权；尤其注意模型权重与训练资产的独立协议。
- FFmpeg 某些预编译二进制启用了 GPL 组件，遵循对应的再发布义务。
- 不把用户的产品片段上传到公开 Github 仓库。
